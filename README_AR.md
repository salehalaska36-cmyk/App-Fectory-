# App Factory AI — حزمة تشغيل محلية

هذه نسخة بداية عملية وليست منصة إنتاج مكتملة. تتضمن واجهة عربية، إنشاء ملفات ويب عبر API، حفظ المشاريع محليًا، معاينة `index.html` وتصدير ZIP. لا تشغّل كود Node أو أوامر طرفية من الذكاء الاصطناعي.

## المتطلبات
- Node.js 20 أو أحدث
- اتصال بالإنترنت عند توليد المشاريع
- مفتاح API من حساب منصة OpenAI مع فوترة/رصيد API صالح

## التشغيل على Windows
1. فك ضغط الملف في مجلد واضح.
2. ثبّت Node.js LTS من الموقع الرسمي: https://nodejs.org/
3. افتح المجلد، ثم افتح Terminal أو PowerShell داخله.
4. نفّذ: `npm install`
5. انسخ `.env.example` إلى ملف اسمه `.env`.
6. افتح `.env` وضع مفتاح API في `OPENAI_API_KEY`، واضبط `OPENAI_MODEL` على اسم نموذج متاح في حسابك. لا تشارك المفتاح ولا ترفعه إلى GitHub.
7. نفّذ: `npm start`
8. افتح `http://127.0.0.1:3000` في المتصفح.

## الموجود الآن
- واجهة عربية محلية
- اتصال Responses API عند ضبط المفتاح
- حفظ المشاريع والملفات على الجهاز
- حالة بناء ومعلومات الخطأ
- معاينة HTML في إطار مع قيود متصفح أساسية
- تنزيل ملفات المشروع ZIP

## غير الموجود بعد
هذه ليست منصة Bolt كاملة أو جاهزة للنشر التجاري. لا يوجد حاليًا تسجيل دخول أو خطط اشتراك أو لوحة إدارة أو دفع أو GitHub OAuth أو بناء APK/AAB أو تشغيل آمن لمشاريع React/Node أو نشر سحابي. المعاينة الحالية مناسبة لنماذج HTML/CSS/JS فقط. يلزم اختبار أمني، وتحديد حصص وتكلفة، وعزل أقوى، ومخزن بيانات مناسب قبل فتح الخدمة للآخرين.

## استكشاف الأخطاء
- `AI is not configured`: تأكد أن الملف اسمه `.env` وليس `.env.example` ثم أعد تشغيل الخادم.
- خطأ النموذج: استخدم اسم نموذج متاحًا في صفحة API الخاصة بحسابك.
- المنفذ مستخدم: غيّر `PORT` في `.env`.
- أوقف الخادم بـ `Ctrl+C`.
